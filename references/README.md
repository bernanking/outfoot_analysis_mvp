# 참고자료 보관 안내

`client-originals`에는 클라이언트가 준 RFP·질문지·화면 캡처 등 원본을 수정하지 않고 넣습니다. `anonymized-samples`에는 분석 개발에 사용하도록 개인정보를 제거한 발도장과 기준 결과를 넣습니다.

실제 환자 이름, 전화번호, 얼굴, 문진 원문, 비식별되지 않은 이미지는 Git에 커밋하지 않습니다. 자료별로 출처, 사용 허용범위, 비식별 확인, 기준값 작성자, 수집일을 별도 목록으로 관리합니다.

현재 검토한 주요 원본은 다음과 같습니다.

- `OUTFOOT_족부분석플랫폼_MVP_사전질문지_대면상담_재구성안 (1).docx`
- 족부 상담·분석 MVP RFP와 자료요청서
- 클라이언트 참고 UI 및 발도장·기존 AI 결과 이미지

원본에 포함된 기능이 모두 승인된 MVP 범위는 아닙니다. 최신 기준은 `docs/02_DECISIONS.md`입니다.

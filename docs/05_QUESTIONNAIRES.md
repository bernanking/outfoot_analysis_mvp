# 환자 사전질문지 명세

## 구성 원칙

질문지는 상담별 고유 링크 하나로 열립니다. 환자는 `NAIL`, `PAIN_INSOLE`, `BOTH` 중 하나를 선택합니다. 저장값은 `concernTypes: ['NAIL']`, `['PAIN_INSOLE']`, 또는 두 코드이며 `BOTH`라는 제3 분석유형을 만들지 않습니다.

공통 문항은 한 번만 묻고 유형별 중복 질문은 제거합니다. 사전 답변은 제출 스냅샷과 `questionnaireVersion`을 보존합니다. 시술자가 방문 시 확인·정정한 내용은 원답 행을 수정하지 않고 별도 확인 기록으로 저장합니다.

## 환자 흐름

동의 → 기본정보 확인 → 상담 유형 → 공통 질문 → 발톱 분기 및/또는 통증·인솔 분기 → 선택 사진 → 확인 → 제출입니다. 뒤로 이동해 수정할 수 있으나 제출 후에는 직접 덮어쓰지 않습니다. 개인정보 동의문과 외부 AI 활용 안내문은 O07 확정 전 초안 표시입니다.

## 제안 상태인 운영 규칙

- `없음`과 다른 값은 상호배타적입니다.
- 사진 파일은 JPG·PNG·WEBP를 우선 허용하고 크기 제한은 P09입니다.
- 환자는 질문지에서 최종 진단·시술 결과를 받지 않습니다.
- 문항 문구·동의문·주의 트리거는 실제 공개 전에 클라이언트·전문가 최종 확인이 필요합니다.

## T04A 정적 화면 검토 범위

- 문항마다 이 문서의 필수·선택 구분을 표시합니다. N05는 N02의 `통증`, P15는 C13의 `인솔 상담` 선택 시에만 화면에 나타납니다. 두 유형을 함께 선택해도 공통 문항은 한 번만 표시합니다.
- C13의 유형별 세부 선택지는 O03 확인 대상이며 현재 화면 선택지는 분기 검토용 제안입니다. `유형별 선택지 확정 전`이라고 표시합니다.
- P11에는 주당 횟수 입력, P12에는 환자가 알고 있는 발길이의 `mm 또는 모름`을 표시합니다. P12 값은 실측값으로 취급하지 않습니다.
- 질문지 단계 이동 시 단계 제목에 키보드 포커스를 옮기고 화면 상단으로 스크롤합니다. C01 미선택 오류는 `다음`을 누른 뒤 표시합니다.
- 정적 화면 입력은 저장·제출되지 않습니다. 숨은 조건부 답변의 제출 정리와 실제 링크 검증은 T07 범위입니다.

# 확정 사항과 제안 및 보류 기록

버전 1.1 · 2026-09-22. 이 문서는 요구사항 상태의 기준 원본입니다.

## 상태의 의미

- **확정**: 사용자가 직접 명시하거나 제안을 수용한 내용.
- **구현 제안**: 개발을 진행하기 위한 기본 설계. 고객이 직접 승인한 사실로 표현하지 않습니다. 가역적인 개발은 이 안으로 진행할 수 있습니다.
- **보류**: 샘플·전문 기준·운영 결정이 필요합니다. 관련 없는 작업까지 중단하지 않습니다.
- **제외**: 이번 MVP 구현 대상이 아닙니다.

## 과거 문서와 달라진 부분

| 과거 표현 | 현재 기준 |
| --- | --- |
| 문제 유형 3개 독립 질문지 | 2개 유형 + 복합 분기, 공통 문항 한 번 |
| 접수 시 유형을 확정하여 다른 유형 질문 불가 | 환자 선택, 시술자 대면 보완 가능 |
| 질문지·규칙·콘텐츠 CMS | MVP 제외, 코드·파일 버전 관리 |
| 지정 격자·네 모서리 마커 필수 | 용지·보정 방법은 샘플로 결정, 특정 제품 강제 아님 |
| 자동 정량분석·OpenCV 확정 | 목표 항목, 기술과 구현 범위 보류 |
| ChatGPT API 단독·수동 측정으로 대체 확정 | 제안이었으며 채택되지 않음 |
| 기존 챗지피티 대화방을 직접 API 호출 | 제공된 지침·자료를 API용으로 재구성 |
| 자동저장·제품 마스터·비교·재방문 관리함 | 명시적 저장·고정 선택·회차 조회·재방문 메모 |
| 모든 사진·AI·재방문일이 없으면 어떤 결론도 금지 | 의료기관 확인·보류는 이유와 담당자 확인으로 종료 |
| 4주·대표사례 10명·총30명 확정 | 이전 제안, 납기·표본·오차 재합의 필요 |
| 토스 React 컴포넌트 Vue 직접 적용 | PrimeVue 기반 OUTFOOT 자체 테마로 확정 |
| JavaScript·Vue·Node.js·NoSQL·Cloudflare 후보 | TypeScript·Vue 3·Workers·D1(SQL)·R2로 확정 |
| AWS 실제 구축 승인 | Cloudflare 구성을 선택했으며 실제 원격 자원 생성은 아직 없음 |

## 검토한 출처와 한계

- 전체 대화의 최종 기능표, 최소 기능 요청, 1~8번 제안 수용, 기술 지정, 발도장 분석 보류 결정.
- `OUTFOOT_족부분석플랫폼_MVP_사전질문지_대면상담_재구성안 (1).docx`의 1~22절 전체. 문항 원문은 [질문지](05_QUESTIONNAIRES.md)와 [대면 상담](06_VISIT_FIELDS.md)에 매핑했습니다.
- 기존 RFP v0.2와 자료요청서의 범위·촬영·일정 표현을 대조했습니다. 최신 합의와 다르면 본 문서의 수정 기준을 적용합니다.
- 첨부 UI 스크린샷은 참고 화면입니다. 예약·주문·자동발송·더미 통계가 그려져 있어도 요구 확정 근거로 삼지 않습니다.
- 기존 AI 결과의 정상 점수, 함몰 비율, 보조기 유형, 단계 점수는 검증된 표준으로 채택하지 않습니다.
- 동의문·의학 지식·측정 기준의 전문 검증은 완료되지 않았습니다.

## 변경 기록 규칙

새 결정은 날짜, 요청자, 변경 내용, 영향 문서, 상태를 표에 추가합니다. 의사결정 대기 때문에 개발 전체를 멈추지 말고 관련 없는 T 작업을 진행합니다. 출시 차단 조건은 [검수 문서](14_ACCEPTANCE_TESTS.md)를 따릅니다.

## T04 검수 반영 · 2026-09-23

- 모바일 메뉴를 열면 첫 메뉴 항목에 포커스를 옮기고 본문을 `inert` 처리합니다. 사이드바의 닫기 버튼·바깥 영역·Esc로 닫을 수 있으며 Esc 뒤에는 메뉴 버튼으로 포커스가 돌아갑니다. 모바일 상단에 `시안` 배지와 접근 가능한 `미리보기 역할` 라벨을 유지합니다.
- 입력 래퍼의 속성 중복을 제거하고 버튼 속성을 PrimeVue 타입에 맞춰 선언했습니다. 텍스트용 청록과 실제 보조문자 토큰을 디자인 문서에 반영했습니다.
- 관리자 시안 메뉴에 상담 기록·감사 기록 링크를 분리하고 감사 기록 준비 경로를 추가했습니다. 오류 화면의 재시도 오인 동작을 제거하고, 직접 진입한 404의 이전 화면 버튼은 상담 목록으로 이동하게 했습니다. 로그인 필수 오류는 첫 오류 입력으로 포커스를 옮깁니다.
- 라우터, 역할별 메뉴, 입력 속성 전달과 모바일 메뉴 포커스를 검증하는 웹 테스트를 추가했습니다. 테스트 도구는 MIT 라이선스의 Vue Test Utils 2.5.1·jsdom 30.1.1로 고정하고 루트 lockfile을 갱신했습니다.
- 남은 제한: 768~1279px 좌측 메뉴 축소, 시안 역할의 Pinia 공유와 관리자 경로 가드는 T04A에서 처리합니다. 사용하지 않는 `services/api.ts`의 데모 호출과 API `/demo` 경로는 삭제하지 않았으며 T02 전에 정리합니다. 로그인·권한·기록 화면은 여전히 정적 시안입니다.
- 당시 검증(최신 결과는 아래 재검수 기록): `npm run typecheck`, `npm run lint`, `npm test`(API 2·웹 8·계약 2, 총 12개), `npm run build`, `git diff --check` 통과. 브라우저 360px에서 메뉴 열기·첫 항목 포커스·Tab·Esc·닫기 버튼·상단 `시안` 배지를 확인했습니다. 768px과 1280px에서는 고정 메뉴와 상단 시안 배지를 확인했으며, 이 크기에는 메뉴 토글이 없어 열기·닫기 동작 대상이 아닙니다. 직접 연 404의 이전 버튼이 상담 목록으로 이동하고, 로그인 필수 오류가 첫 오류 입력에 포커스를 옮기는 것도 확인했습니다.

- 남은 제한: 768~1279px 메뉴 축소와 시안 역할 공유·관리자 경로 가드는 T04A 대상입니다. 정적 시안의 인증·권한·업무 기능은 연결되지 않았고, 데모 API 경로 정리는 T02 전 예정입니다. 다음 작업은 T04A 정적 화면·링크·합성 상태 구성입니다.

## T04 검수 반영 · 2026-09-23

- 모바일 메뉴를 열면 첫 메뉴 항목에 포커스를 옮기고 본문을 `inert` 처리합니다. 사이드바의 닫기 버튼·바깥 영역·Esc로 닫을 수 있으며 Esc 뒤에는 메뉴 버튼으로 포커스가 돌아갑니다. 모바일 상단에 `시안` 배지와 접근 가능한 `미리보기 역할` 라벨을 유지합니다.
- 입력 래퍼의 속성 중복을 제거하고 버튼 속성을 PrimeVue 타입에 맞춰 선언했습니다. 텍스트용 청록과 실제 보조문자 토큰을 디자인 문서에 반영했습니다.
- 관리자 시안 메뉴에 상담 기록·감사 기록 링크를 분리하고 감사 기록 준비 경로를 추가했습니다. 오류 화면의 재시도 오인 동작을 제거하고, 직접 진입한 404의 이전 화면 버튼은 상담 목록으로 이동하게 했습니다. 로그인 필수 오류는 첫 오류 입력으로 포커스를 옮깁니다.

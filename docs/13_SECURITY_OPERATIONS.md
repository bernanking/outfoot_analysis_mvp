# 보안과 운영 기준

이 시스템은 건강 관련 상담정보와 발 이미지를 다루므로 실제 환자 데이터 수집 전 운영 주체의 개인정보·외부 AI 사용 정책을 확정해야 합니다. 본 문서는 기술 기본선이며 법률·의료 자문을 대체하지 않습니다.

## 접근·데이터 보호

- 관리자 공개가입을 만들지 않고 최초 계정은 운영자가 생성합니다. 비밀번호는 강한 해시로 저장하고 로그인 제한·세션 만료·비활성화를 적용합니다.
- 모든 API와 파일 조회에서 기관·담당자·역할 권한을 검사합니다. 화면에서 버튼을 숨기는 것만으로 권한을 구현하지 않습니다.
- HTTPS를 사용하고 운영 D1·R2는 공개하지 않습니다. R2 객체는 Worker의 권한 검사나 짧게 만료되는 URL을 통해서만 제공합니다.
- 파일 확장자가 아니라 실제 MIME, 크기, 픽셀, 디코딩 성공을 검사하고 임의 파일명으로 저장합니다. SVG·실행파일은 받지 않습니다.
- AI 공급자 키와 외부 서비스 비밀값은 Cloudflare 비밀관리로 주입하며 Git·브라우저·로그에 넣지 않습니다.
- AI 전송 전에 이름·전화·고객번호를 제거합니다. 이미지 전송 여부와 보관 정책은 O07에 따릅니다.
- 개인정보를 로그에 남기지 않고 requestId, 행위자, 엔터티 ID, 결과 코드 중심으로 기록합니다.

## 공개 질문지 링크

토큰 원문은 DB에 저장하지 않고 해시를 저장합니다. 추측하기 어려운 길이를 사용하고 만료·폐기·제출 상태를 검사합니다. 검색엔진 색인을 막고 속도 제한을 둡니다. 토큰 하나로 해당 상담 질문지 외 환자정보·과거회차·파일을 조회할 수 없습니다.

## 감사 대상

로그인 성공·실패, 계정 상태 변경, 환자·상담 핵심정보 변경, 링크 발급·폐기, 제출, 파일 등록, 발도장·AI 실행, 최종확정·개정, 삭제를 기록합니다. 민감 답변 원문과 비밀값은 감사 metadata에 복사하지 않습니다.

## 백업·복구

운영 DB 자동백업, 이미지 객체 버전·수명 정책, 배포 전 DB 스냅샷, 마이그레이션 롤백 또는 forward-fix 절차를 제안합니다. 보관기간·복구 목표·비용은 O07·O08에서 확정합니다. 백업 존재 여부만 보지 않고 스테이징에 복구 시험을 수행합니다.

## 배포 기준

Vue 정적 자산은 Workers Assets, API는 Workers, 업무 데이터는 D1, 이미지는 비공개 R2에 배포합니다. 개발·스테이징·운영 환경의 바인딩과 비밀값을 분리하고 로그·오류·비용 알림을 설정합니다. GitHub 자동배포 자격증명은 대상 계정과 프로젝트로 권한을 최소화합니다.

실제 Cloudflare 원격 자원 생성은 별도 허용과 계정·비용·데이터 위치 요구 확인 후 수행합니다. 계정 비밀번호·MFA 복구값·API 토큰 원문을 채팅이나 저장소에 전달하지 않습니다.

## 운영 전 체크

동의·보유·파기·외부처리 정책 승인, 관리자·운영 담당자 지정, 계정회수 절차, 도메인·인증서, 백업·복구시험, 경보 수신처, 취약점·의존성 점검, 스테이징 검수, 지원·장애연락 절차가 필요합니다.

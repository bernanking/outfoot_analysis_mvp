# 대면 상담 입력 명세

## 공통 입력

| ID | 항목 | 형식 | 필수·처리 |
| --- | --- | --- | --- |
| V01 | 환자 주호소 원문 | 읽기전용 | 사전 원답 보존 |
| V02 | 오늘의 주호소·대표 목표 | 장문 + 대표 1개 | 필수 |
| V03 | 사전 이후 변화 | 호전/동일/악화/새 증상 + 메모 | 필수 |
| V04 | 현재 불편점수 | 0~10 | 필수, 사전점수 옆 표시 |
| V05 | 안전정보 재확인 | 질문별 확인값 | 조건부 필수, 확인자·시각 |
| V06 | 생활·업무·운동 | 선택 + 메모 | 선택 |
| V07 | 주사용 신발·착화 | 종류·사이즈·압박·마모 | 필수 |
| V08 | 이전 진료·관리 반응 | 장문 | 선택, 환자 전달 정보 표시 |
| V09 | 현장 관찰 | 사실 관찰 / 시술자 판단 분리 | 선택 |
| V10 | 오늘 진행 결정 | 관리 검토/추가확인/의료기관 우선/보류 | 필수 |

## 발톱 상담

| ID | 항목 | 최소 입력 |
| --- | --- | --- |
| NV01 | 대상·대표 발톱 | `L1~R5` 복수 + 대표 1개 |
| NV02 | 통증·압박 | 현재·압박 시 점수, 위치 |
| NV03 | 형태 | 두께·만곡·파고듦·들뜸·갈라짐을 고정 선택+메모 |
| NV04 | 색·표면 | 관찰색과 범위, 표면 변화 |
| NV05 | 주변조직·피부 | 붉음·부종·열감·상처·출혈·진물·피부 변화 |
| NV06 | 진균 관련 | 검사·진단·시기·반응, 외관 확정 금지 |
| NV07 | 기계적 요인 | 신발·발가락·보행·절단습관·외상 |
| NV08 | 관리 적합성 초안 | 가능/조건부/의료기관 우선/보류 + 근거 |
| NV09 | 예정 관리·홈케어 | 고정 범위+메모. 세부 시술 종류는 고객 확정자료 필요 |
| NV10 | 추후 확인 | 날짜 또는 주기 또는 미정 사유 |

## 통증·구조·인솔 상담

| ID | 항목 | 최소 입력 |
| --- | --- | --- |
| PV01 | 관심·대표 부위 | 좌우 복수 + 대표 1개 |
| PV02 | 불편·유발·제한 | 현재·최고 점수, 상황, 기능제한 |
| PV03 | 정적 관찰 | 아치·뒤꿈치·전족부·발가락·좌우 차이 메모 |
| PV04 | 피부·압박 흔적 | 굳은살·티눈·홍반·마찰 위치 |
| PV05 | 선택 검사 | 발목 가동·엄지 기능·균형, 미실시 허용 |
| PV06 | 보행 관찰 | 진행각·접지·체중이동·보폭 메모, 영상 자동분석 제외 |
| PV07 | 수동 실측 | 좌우 길이·폭 mm 또는 미측정, 방법 기록 |
| PV08 | 신발 적합성 | 내부공간·앞코·발등·뒤꿈치·마모 |
| PV09 | 발도장 상태 | 좌우 파일, 품질, 촬영·분석불가 사유 |
| PV10 | 분석 결과·보완 | 자동 원본과 시술자 보완값·이유 분리 |
| PV11 | 인솔 검토 | 목적·고정 유형·설계 메모, 주문·제품마스터 제외 |
| PV12 | 추후 확인 | 적응·주의·재평가 계획 또는 미정 사유 |

## 종합분석 전 입력

발도장 결과가 있을 때는 좌우 결과와 신뢰·품질 상태를 함께 전달합니다. 없거나 측정 불가한 값은 누락 이유를 전달합니다. 시술자 보완에는 이미지로 판단하기 어려운 사항, 실측값, 현장 관찰과 해석을 구분합니다.

의료기관 확인·보류 결론에서는 케어 계획 대신 이유·안전 안내·확인 담당자를 저장할 수 있습니다. 일반 케어 확정 필수값과 AI 차단 조건은 O04·O05 결정 후 조정합니다.

# OUTFOOT MVP 제품 요구사항

버전 1.0 · 2026-09-22 · 세부 상태의 원본은 [결정 기록](02_DECISIONS.md)입니다.

## 목적과 사용 맥락

현재 환자 접수, 외부 설문, 대면 상담, 엑스바디 결과 또는 발 이미지의 ChatGPT 해석, 시술자 판단이 분산되어 있습니다. MVP는 이를 환자별 상담 회차에 연결하고 AI 분석 초안에 시술자가 보완·확정하는 업무를 지원합니다.

발 스캔 장비의 일부 역할을 대체하는 것은 검증할 사업 목표입니다. 장비 전체 기능, 정밀 족저압, 의료적 진단을 이미 대체할 수 있다고 약속하지 않습니다. 사진 분석 방식과 산출 항목은 샘플 검증 결과로 정합니다.

예산 배경은 700만 원입니다. 부가세 포함 여부, 운영비·API비 포함 여부, 납기와 검수 표본 수는 아직 확정된 개발 계약 조건으로 보지 않습니다. 과거 4주·10명·30명 등의 예시는 확정 일정·검수량이 아닙니다.

## 사용자

| 사용자 | 목적 |
| --- | --- |
| 시술자 | 환자·상담 등록, 방문 정보와 이미지 입력, AI 검토, 최종 결과 작성 |
| 환자 | 로그인 없이 이번 상담의 질문지 작성과 선택 사진 첨부 |
| 관리자 | 시술자 계정·담당자 관리, 기관 내 기록 조회·관리, 상담 삭제 |

기관 한 곳의 초기 운영을 제안 기준으로 삼고 데이터에는 기관 ID를 둡니다. 다기관 가입·결제·구독은 범위에 포함하지 않습니다.

## 제품 흐름

상담 등록에서 고유 링크를 생성합니다. 환자가 공통 질문과 선택한 유형의 질문에 응답하면 해당 회차에 연결합니다. 방문 시 담당자가 원답과 추가 확인값을 구분해 기록합니다. 필요한 이미지를 등록하고 가능한 범위의 발도장 분석 및 시술자 보완을 거쳐 AI 종합분석을 실행합니다. AI 결과를 검토한 담당 시술자가 최종 상담 결론과 고객 안내를 확정합니다.

발톱 단독 상담은 발도장이 선택입니다. 통증·인솔 유형은 좌우 발도장 등록을 기본 흐름으로 제시합니다. 촬영 불가·분석 불가 사유를 남길 수 있으며 그것만으로 정상 분석이나 일반 케어 확정을 허용하지 않습니다. 구체적인 우회 조건은 보류 사항입니다.

## 기능 범위

| ID | 사용자·기능 | 요구사항 | 상태 |
| --- | --- | --- | --- |
| FR-01 | 로그인·계정 | 시술자·관리자 로그인, 사용중지, 관리자 계정 발급·초기 비밀번호 재설정 | 포함 |
| FR-02 | 환자 관리 | 이름·연락처·성별·출생연도 또는 기록시점 나이 등록·조회·수정 | 포함 |
| FR-03 | 상담 관리 | 환자와 별도로 회차 생성, 담당자 지정, 진행상태·상담 이력 조회 | 포함 |
| FR-04 | 환자 질문지 | 상담별 링크, 유형 선택, 고정 공통·분기 문항, 동의·제출 | 포함 |
| FR-05 | 방문 상담 | 원답 조회, 확인값·통증·생활·신발·현장 관찰 입력 | 포함 |
| FR-06 | 사진·발도장 | 유형과 좌우 태그, 개별 업로드·확대·원본 보존, 실패 안내 | 포함 |
| FR-07 | 발도장 분석 | 분석 실행·상태·결과·실패 표시, 목표 지표의 검증 및 구현 | 기술·실제 산출 항목 보류 |
| FR-08 | 분석 보완 | 자동·AI 관찰과 별도로 시술자 실측·관찰·보완 이유 저장 | 포함 |
| FR-09 | AI 종합분석 | 질문·방문·이미지 관련 결과·보완정보를 이용해 구조화된 검토 초안 작성 | 포함, 지식·검증자료 필요 |
| FR-10 | 결과 확정 | AI 원본과 시술자 최종본 분리, 확정자·시각·버전 저장 | 포함 |
| FR-11 | 결과 조회·출력 | 회차별 상담·이미지·분석·최종본 조회, 확정 고객안내 인쇄 | 포함 |
| FR-12 | 관리자 | 시술자·담당자 관리, 기관 기록 조회, 사유를 남긴 상담 삭제 | 포함 |
| FR-13 | 보호·오류 | 권한·감사기록, 중복 제출·동시수정·오래된 분석 방지, 실패·재시도 | 포함 |

기록 조회는 환자 상세의 회차 목록에서 상담 상세를 여는 한 기능으로 통합합니다. 분석·보완·확정은 상담 작업 화면 내 탭으로 구성하고 별도 중복 메뉴를 만들지 않습니다.

## 목표 분석 항목과 보류 범위

발 길이·폭, 접촉면적, 전·중·후족부 비율, 아치 관련 지표, 내·외측 접촉형태, 좌우 비대칭, 평발·요족 경향이 검토 대상입니다. 각 항목의 입력 조건·정의·허용오차·검증방법·비용을 합의한 후 지원 여부를 확정합니다. 일반 A4 네 점 표시만으로 접촉면적을 계산하거나 사진 농도를 압력으로 환산하지 않습니다.

기술이 미정이어도 이미지 업로드, 분석 상태 표시, 결과를 담는 인터페이스, 보완입력 화면은 개발할 수 있습니다. 실제 분석이 없는 상태에서 가짜 정상 판정·점수를 넣지 않습니다.

## 최소 구현 원칙

- 질문지·문항·분석 요청문은 코드·버전 파일로 관리하며 CMS를 만들지 않습니다.
- 문항은 선택버튼·체크박스·메모 중심으로 구성합니다. 해부학 그림 편집기는 제외합니다.
- 관심 부위는 여러 개 선택하되 유형별 대표 부위 한 곳을 상세 기록합니다.
- 인솔은 목적·유형 선택과 메모만 제공합니다. 제품 마스터·주문을 만들지 않습니다.
- 저장은 명시적 임시저장과 이탈 경고로 시작합니다. 자동저장·동시 편집 잠금은 제외하고 버전 충돌을 알립니다.
- 일반 상담 결과에서 AI 원본·시술자 최종본을 구분합니다. 제안마다 채택·제외하는 별도 워크플로는 제외합니다.
- 의료기관 확인·보류 결론은 AI 케어 초안이나 재방문 날짜가 없어도 사유와 담당자 확인으로 마칠 수 있게 합니다.

## 제외 기능

공개 회원가입, 환자 회원계정·마이페이지, 질문지 관리자 편집, 자유 규칙 편집기, 예약 캘린더, SMS·카카오·이메일 자동발송, 주문·재고·결제, 제품 추천 엔진, 고급 통계, 과거 사진 나란히 비교, 이전 회차 일괄 복사, 보행 영상 자동분석, 외부 장비 실시간 연동, 3D·절대 압력, 자동 확정 진단, 네이티브 앱, 모델 자동학습·파인튜닝은 포함하지 않습니다.

## 품질과 출시 기준

- PC 상담 화면과 모바일 환자 질문지를 우선 검증합니다. 모바일 시술자 주요 조회·입력도 지원합니다.
- 일반 조회 화면 3초 이내 목표는 합의한 데이터량·네트워크·측정방법에 한해 평가합니다. AI 처리시간에는 적용하지 않습니다.
- 접수부터 최종확정까지 연결, 원본 보존, 권한, 질문지 분기, 실패 복구를 [검수 기준](14_ACCEPTANCE_TESTS.md)으로 확인합니다.
- 실제 환자 운영은 동의·보관·AI 사용 범위·전문 기준·배포 운영 정책의 확인 후 시작합니다.
- 발도장 기술검증 미완료는 숨기지 않습니다. 고객 합의 없이 전체 기능 완료로 처리하지 않습니다.

## 성공 확인 항목

시범 운영에서 상담 작성 완료율, 누락·재촬영 빈도, AI 수정 필요 항목, 처리시간·건당 비용을 관찰합니다. 목표 수치는 베이스라인과 샘플을 확인한 후 정합니다. 연간 매출·재방문 목표는 사업 목표이며 이 MVP의 합격 수치로 자동 적용하지 않습니다.
